# Castaway Continuum fork notice

Castaway Continuum is a private GPL-3.0-or-later fork of Wilson Reborn, created
to package a focused Windows Johnny Castaway experience with the V1.0.0 identity.

The repository retains the corresponding source, build scripts, packaging
templates, documentation, and the owner-supplied private test resource set needed
to reproduce its embedded Windows build. Generated build output and old release
archives are deliberately excluded.

Wilson Reborn remains the upstream technical lineage. Its relevant copyright and
license notices remain intact; this fork does not claim ownership of the original
Sierra/Dynamix Johnny Castaway data.
